# Third-Party Components

Vein Dump Manager includes or integrates with the following third-party tools and runtime files.

## UE4SS-Vein

- Upstream project: `Alustrial/UE4SS-Vein`
- Purpose: UE4SS runtime support for VEIN dump hotkeys, Lua logs, mod reloads, signatures, mappings, and UE4SS runtime files.
- Bundled location: `tools/vein-dump-manager-installer/Assets/UE4SS-Vein-runtime/`
- License: see the license file bundled in the runtime folder.

## Cheat Engine

- Cheat Engine is not bundled in this repository.
- The app can detect a local Cheat Engine install and use it for the optional memory dump mode.
- Users are responsible for installing and using Cheat Engine legally and safely.

## VEIN

- VEIN is not bundled in this repository.
- Users must own and install VEIN through Steam.
